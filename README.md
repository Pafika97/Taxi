# Taxi Bid Android (Flutter)

## Подготовка
- Установите Flutter SDK.
- Создайте проект: `flutter create taxi_bid_app` (не обязательно, файлы уже здесь).
- В `lib/main.dart` замените значение константы `backendBase` на адрес вашего бекенда (например, адрес ngrok).

## Сборка APK
```bash
flutter build apk --release
# APK: build/app/outputs/flutter-apk/app-release.apk
```
